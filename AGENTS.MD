# Sitio web de un centro de Fp
---
Este sitio web es una prueba y se usará en una clase de Desarrollo de Interfaces Web.
Consiste en un sitio web para un centro formativo de FP.

## Tecnologias
-Frontend
    -HTMLS (moderno)
    -CSS3
    -Vanilla JS
-Backend
    -Node.js
    -Express 4.22.3
    -Plantillas EJS

## Arquitectura
-Todo en una unica pagina index, dividido por secciones.

## Convenciones del lenguaje
-Usa ingles para las variables y funciones

## Contenido 
- El contenido debe ser realista
-El contenido debe estar en ingles
-Las imagenes por defecto son de picsum.photos

## Limitaciones
-No usar grid
